## FluidX — бета 0.2.0

**Бета-версия.** Жесты iPhone X для устройств с кнопкой Home на iOS 15 (rootless).

### Что нового в 0.2.0

- **Скорость анимаций** — ползунок 0.5–2.0 для анимаций SpringBoard.
- **Прозрачность домашней полоски** — от 10% до 100%.
- **Цвет домашней полоски** — HEX-код (`FF2D55`, `00A3FF`, …). Пусто = системный.
- **Без блюра (быстрее)** — отключает размытие подложек, разгружает GPU на A10.
- **Сброс настроек** и кнопка **Respring**.
- Раздел **О твике**: ссылки на GitHub, Telegram и лог последней сборки.

### Установка

1. Скачай `.deb` из раздела **Assets** ниже.
2. Открой файл в Filza → **Install**.
3. Respring (Sileo или кнопка в настройках твика).

Прямая ссылка без GitHub-аккаунта — ветка `ci-logs`:

```
https://github.com/vaibcode-dev/FluidX/raw/ci-logs/com.dolboebvaibcode.fluidx_0.2.0-beta_iphoneos-arm64.deb
```

### Что внутри

- родной движок жестов SpringBoard (`SBHomeGestureSettings`, `SBFHomeGrabberSettings`) — без самописных распознавателей;
- настройки: **Настройки → FluidX**;
- Пункт управления — свайп сверху справа, с фиксом анимации.

### Проверить, что твик загрузился

```sh
ls -l /var/jb/Library/MobileSubstrate/DynamicLibraries/ | grep FluidX
```

### Известные ограничения

- на живом iPhone 7 / iOS 15.8.8 не тестировалось;
- цвет и прозрачность полоски — экспериментальные (полоска рисуется системным «материалом»): если цвет не применился, напиши в Telegram;
- только rootless-джейлбрейк (Dopamine / palera1n rootless).
