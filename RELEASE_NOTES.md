## FluidX — бета 0.2.1

**Бета-версия.** Жесты iPhone X для устройств с кнопкой Home на iOS 15 (rootless).

### Главное в 0.2.1

- **Починка раздела настроек.** В пакет добавлена зависимость `preferenceloader`,
  а после установки `postinst` перезапускает Настройки — новый раздел читается
  сразу, без respring.
- **Диагностика.** `postinst` пишет отчёт в `/var/mobile/FluidX-diag.txt`:
  установлен ли PreferenceLoader, где лежат файлы твика, какая версия пакета.
- Содержимое настроек — как в 0.2.0 (см. ниже).

### Установка

1. Удали старую версию: **Sileo → FluidX → Удалить** (это важно: не ставь
   старый `.deb` поверх нового — dpkg сделает понижение версии).
2. Скачай `.deb` из **Assets** ниже и открой его в Sileo (или Filza → Install).
3. В Sileo у пакета должно быть **0.2.1-beta**.
4. Открой **Настройки** — раздел **FluidX** в самом низу списка.
   Если Настройки были открыты — смахни их из свитчера и открой заново.

### Настройки внутри

| Раздел | Что настраивается |
|---|---|
| Жесты iPhone X | включение, показ домашней полоски |
| Домашняя полоска | высота, ширина, прозрачность, цвет в HEX |
| Анимации | скорость интерфейса SpringBoard (0.5–2.0) |
| Производительность | «без блюра» — легче GPU на A10 |
| Пункт управления | свайп сверху справа, фикс анимации |
| Применение | respring, сброс настроек |
| О твике | GitHub, Telegram [@angel_gtag](https://t.me/angel_gtag), лог сборки |

### Проверить, что твик загрузился

```sh
ls -l /var/jb/Library/MobileSubstrate/DynamicLibraries/ | grep FluidX
```

### Известные ограничения

- на живом iPhone 7 / iOS 15.8.8 не тестировалось;
- цвет и прозрачность полоски — экспериментальные: полоска рисуется системным
  «материалом», цвет может примениться не полностью;
- только rootless-джейлбрейк (Dopamine / palera1n rootless).
