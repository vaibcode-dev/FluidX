## FluidX — бета

**Бета-версия.** Жесты iPhone X для устройств с кнопкой Home на iOS 15 (rootless).

### Установка

1. Скачай `.deb` из раздела **Assets** ниже.
2. Открой файл в Filza → **Install**.
3. Respring (Sileo или кнопка в настройках твика).

Прямая ссылка без GitHub-аккаунта — ветка `ci-logs`:

```
https://github.com/vaibcode-dev/FluidX/raw/ci-logs/com.dolboebvaibcode.fluidx_0.1.0-beta_iphoneos-arm64.deb
```

### Что внутри

- родной движок жестов SpringBoard (`SBHomeGestureSettings`, `SBFHomeGrabberSettings`) — без самописных распознавателей;
- настройки: включение жестов, показ и размер домашней полоски, свайп Пункта управления сверху справа, фикс анимации Пункта управления, кнопка respring;
- после установки: **Настройки → FluidX**.

### Проверить, что твик загрузился

```sh
ls -l /var/jb/Library/MobileSubstrate/DynamicLibraries/ | grep FluidX
```

### Известные ограничения

- проверено только сборкой и разбором пакета, на живом iPhone 7 / iOS 15.8.8 ещё не тестировалось;
- работает только на rootless-джейлбрейке (Dopamine / palera1n rootless).
